# AA Embroidery Works — Digital Business Card

Responsive React/Vite implementation using the supplied Figma UI as the visual base.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The layout is responsive: the base composition is preserved, the card uses the available mobile viewport, and the body can scroll on shorter screens while the Save to Contacts control remains sticky at the bottom of the visible content area.
